Aquí recopilamos las notas del curso.

Este curso es una introducción práctica a **Claude Code** y su ecosistema. Está diseñado para que, sin importar tu nivel de experiencia, puedas empezar a usar Claude Code para construir software real de forma más rápida y con mayor control.

# Claude Code es de paga

Sí. Claude Code requiere una suscripción activa de Claude.
Para seguir este curso se espera que ya cuentes con tu cuenta activa y el programa de Claude Code instalado en tu computadora.

No hemos encontrado alternativas gratuitas que brinden una experiencia igual.
Sin embargo te recomendamos la siguiente alternativa, si bien no funcionará de la mejor manera con las notas de este curso, es un buen punto de partida para adentrarse en el mundo de los agentes de código antes de pagar por una suscripción:

[Open Code](https://opencode.ai/). Un agente de IA gratuito de código abierto, muy similar a Claude Code.
